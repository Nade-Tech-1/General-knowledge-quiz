General Knowledge Quiz 🎯

A simple Python quiz game that tests the user's general knowledge with three questions.

Features

- Asks 3 general knowledge questions
- Checks the user's answers
- Keeps track of the score
- Displays the final score
- Accepts answers regardless of capitalization where appropriate

What I Learned

- Using "input()"
- Using variables
- Using "if" and "else" statements
- Comparing strings
- Using ".lower()"
- Updating variables with "+="
- Using f-strings

How to Run

1. Make sure Python is installed.
2. Open the project folder in your terminal.
3. Run:

python quiz.py

Example

The program asks questions and gives feedback after each answer before displaying the final score.
